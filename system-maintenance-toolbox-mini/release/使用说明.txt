系统维护工具箱 mini

直接运行：
Windows 10 / Windows 11 或 64 位 Windows 7，请双击“系统维护工具箱 mini（64位）.exe”。32 位 Windows 7，请双击“系统维护工具箱 mini（32位）.exe”。程序启动时如出现“是否允许此应用对你的设备进行更改？”提示，请选择“是”。运行本程序不需要安装 Python，也不需要运行 build_windows.bat 或打开命令提示符。

界面与交互：
程序窗口支持自由拖动边缘调整大小、最小化、最大化和还原。Wi-Fi 控制区、打印维护区、无线网卡下拉框、刷新按钮、状态栏和绿色进度条会根据窗口客户区大小重新排布和扩展，不会保持固定坐标。操作期间会显示绿色分段进度与阶段说明；成功或失败状态显示约 1.6 秒后，状态文字和进度条会自动消失，恢复空白初始状态。

Wi-Fi 与打印：
Wi-Fi 下拉框优先显示 Windows WLAN 服务识别到的物理无线网卡，并排除 Wi-Fi Direct、Hosted Network、虚拟网卡和常见虚拟化设备。显示格式为“网卡设备名称 [Windows 接口名称]”。清空打印列表时，确认框提供“是 / 否 / 取消”；点击右上角 X 会取消操作。

提示信息：
点击主窗口右上角的“💡 信息”按钮，会打开提示窗口并显示软件图标、By 樱花树下科技工作室·AI创作、项目地址 http://fanxiaofei.ccwu.cc/，以及文件说明、版本、产品名和版权信息。

文件属性：
在资源管理器中右键程序并打开“属性”，可查看文件说明“系统维护工具箱mini”、文件版本“0.05”、产品名“系统维护工具箱mini”、产品版本“0.1.0”和版权“© 樱花科技工作室”。

发布者与 SmartScreen：
本程序的文件属性中文信息已按 UTF-8 资源重新编译。当前程序尚未使用 Authenticode 代码签名证书，因此 Windows 仍会显示“发布者未知”并可能触发 SmartScreen。这不能通过修改文件说明、产品名或版权来解决。若要显示“樱花科技工作室”发布者并建立 SmartScreen 信任，需要由该主体取得受信任的代码签名证书，并对每次发布的 .exe 使用证书和时间戳进行 Authenticode 签名；提供签名证书或签名硬件令牌后即可继续完成此步骤。

编码与发布者：
文件属性页中的中文版本资源已按 UTF-8 代码页重新编译，文件说明、产品名、版权与原始文件名将正常显示。当前程序尚未使用 Authenticode 代码签名证书，因此 Windows 仍会显示“发布者未知”并可能触发 SmartScreen；修改文件属性不能改变这一状态。若要显示“樱花科技工作室”发布者，需要以该主体申请受信任的代码签名证书，并在每次发布时对 `.exe` 进行带时间戳的签名。

进度与信息窗口：
操作期间，绿色进度条会从 0% 平滑递增，并在状态栏右侧显示实时百分比。完成或失败约 1.6 秒后，进度条、百分比和状态文字会被强制隐藏并清空。右上角“💡 信息”窗口已经扩大，正文会完整显示，署名为“By 小潘·樱花树下科技工作室·AI创作”。

界面重绘与 Logo：
新版已移除会在缩放中反复遗留边框的静态分区控件，改为由主窗口统一绘制三个圆角分区背景。窗口调整大小时会先清除旧区域，再将所有控件按新客户区尺寸一次性重排，避免出现嵌套边框和残影。主窗口和“💡 信息”窗口的可见 Logo 已替换为用户提供的第三张图片。

稳定窗口与标题栏图标：
本稳定版已移除最大化按钮和边框缩放能力，窗口维持固定尺寸，避免缩放导致界面异常；仍可通过标题栏移动窗口、通过最小化按钮收起程序并使用右上角关闭按钮退出。标题栏左上角的小应用图标以及任务栏图标已由最新 Logo 源图重新生成，包含 16–256 px 的多尺寸资源。

网卡选择与交付验证：
程序初始只显示“选择无线网卡”按钮，启用与禁用按钮保持不可用。点击后，程序枚举物理无线网卡并显示不可手动编辑的下拉列表；只有用户从列表明确选择设备后，启用和禁用按钮才可点击。命令行原始错误输出不再直接显示，失败提示会以中文说明和错误代码展示，避免乱码。此版本已在 Wine + Xvfb Windows 兼容运行环境中实际启动，验证了固定窗口、初始隐藏网卡列表、点击后显示只读下拉框以及中文界面文字不重叠。

状态摘要：
选择无线网卡后，网卡按钮下方会显示“当前状态”，包括已禁用、已启用且已连接、已启用但未连接、设备未就绪或无法读取接口状态。打印维护区右侧会显示三行摘要：打印服务状态、打印作业数量及作业状态；作业状态可为无打印机、空闲、打印、等待、暂停或异常。点击“刷新状态”可重新读取打印服务与本地/已连接打印机的作业摘要；重启服务或清空打印列表后也会自动刷新。

标题栏与稳定性：
本版本保留 Windows 标准系统菜单、最小化和关闭按钮；固定窗口的缩放与最大化命令会被忽略。程序采用单实例保护：连续双击或重复启动时，第二个进程会自动退出并尝试激活已打开的窗口，不会关闭正在运行的主程序。32 位和 64 位成品均使用资源编号 201 的同一套新标题栏图标，并以“单实例稳定版”新文件名交付，以避免资源管理器继续显示旧图标缓存。

系统图标双击保护：
标题栏左上角图标单击仍可打开标准系统菜单；程序会拦截该区域的双击关闭消息，因此快速双击图标不会再关闭主窗口。右上角关闭按钮及菜单中的“关闭”命令仍然正常可用。

标题栏双击核心修复：
系统图标双击会先触发非客户区双击消息，部分 Windows 环境随后仍可能派发默认关闭命令。程序现在在检测到该双击后启动 900 毫秒关闭抑制保护：保护期内紧随而来的系统关闭命令会被忽略；保护期结束后，右上角关闭按钮、Alt+F4 与菜单中的关闭仍按 Windows 默认行为工作。修复版已在 Windows 兼容环境中按“系统图标双击 → 系统关闭命令 → 保护期结束 → 正常关闭”的完整消息链验证。
