这座阁楼里装着什么

「云隐阁」是一份以 function main(config) 为入口的 mihomo 配置覆写脚本，基于 AIsouler/MyClash 的 mihomoScript.js 微改并国风二次元化：节点自动识别归池、策略组雅号体系、专项分流、机场私有 DNS 与 hosts 解析修复，一卷俱全。

节点归类中国香港（香江）、中国澳门（濠镜）、中国台湾（宝岛）、日本（东瀛）、新加坡（狮城）、美国（花旗）等分池，并单列轻羽·低倍与重岳·高倍。

连接增强sniffer 域名嗅探回落、chrome TLS 指纹、30s 空闲保活与「御风」50ms 容差自动测速，四项合围超稳低延迟。

长卷上的策略名

「太一」主道总入口，统领地区组、基础组与自建节点，万流归宗。

「御风」自动 / 「混元」均衡全节点延迟自动择优与粘性负载均衡，始终走在最低延迟线路上。

香江 / 濠镜 / 宝岛 / 东瀛 / 狮城 / 花旗中国香港、中国澳门、中国台湾与海外地区的自动择优分池，按订阅节点自动生成。

映画·油管 / 天工·灵智 / 飞书·电报 等YouTube、AI、Telegram、Netflix、Steam 等十余项服务的专项分流入口。

「凡尘」直连 / 结界·拦截中国大陆服务优先直连与广告拦截结界，未命中流量归于「补天」兜底。

分流与使用一览

规则依次处理私有网络、国内游戏与厂商直连、广告结界、十余项专项分流、国内外大分流与兜底。使用时在 Clash Verge Rev、Mihomo Party 或兼容 mihomo 的覆写脚本入口粘贴脚本或导入下方 Raw 链接，并关闭客户端自带 DNS 覆写。
