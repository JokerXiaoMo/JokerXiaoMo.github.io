山海行箧 · 开源长卷

番小绯的国风脚本 · 山海行

让代理策略像山海长卷一样清晰；国风命名之下，每一条分流都保留可解释的技术归途。

这只行箧里装着什么

“山海行”是面向 FlClash 的 JavaScript 覆写脚本，以 function main(config) 为入口，为已聚合为 Mihomo 配置的订阅动态分类节点、生成区域测速组和业务策略组。

节点归类港澳、台湾、日本、新加坡、美国与其他节点分池。

测速机制区域组采用 url-test，600 秒复测、50ms 容差并按需启动。

长卷上的策略名

🌺 代理选择全局总开关，始终置于第一位。

☁️ 万象节点全部有效节点的自动测速池。

🏮 香江灯影 / 🍑 东海桃影港澳与日本等区域节点的自动择优。

📜 灵枢智算 / 🧰 百工工坊AI 服务与开发者服务的手动策略入口。

🧧 神州直连 / 🌺 桃源归途大陆服务优先直连与最终兜底策略。

分流与使用一览

规则会依次处理局域网、广告、AI、影音、Google、开发平台、中国大陆、通用海外服务与最终兜底。使用时，在 FlClash 的“配置 → 覆写脚本”创建脚本后选择“导入 URL”，保存并关联订阅；刷新后确认“🌺 代理选择”位于第一项。
