系统维护工具箱 mini

直接运行：
1. Windows 10 / Windows 11 或 64 位 Windows 7：请双击“系统维护工具箱 mini（64位）.exe”。
2. 32 位 Windows 7：请双击“系统维护工具箱 mini（32位）.exe”。
3. 程序启动时会显示“是否允许此应用对你的设备进行更改？”提示，请选择“是”。
4. 不需要安装 Python，不需要运行 build_windows.bat，也不需要打开命令提示符。

本版本修复：
- 窗口支持拖动边缘自由调整大小，并具有最小化、最大化和还原按钮。
- 清空打印列表的确认框提供“是 / 否 / 取消”；可点击右上角 X 关闭并取消操作。
- Wi-Fi 仅优先显示 WLAN 服务识别的物理无线网卡，并排除 Wi-Fi Direct、虚拟网卡、Hosted Network、Hyper-V、VMware 与 VirtualBox 等虚拟设备。
- 进度区域改为绿色分段进度条，按照读取网卡、停止服务、清空队列、恢复服务等实际阶段更新；成功或失败后会展示最终状态。
- 程序窗口左上角与界面页首均已使用本软件图标。

功能：
- 启用或禁用 Wi-Fi。
- 重启打印机服务。
- 清空本地打印列表（会二次确认）。

提示：
- Wi-Fi 下拉框显示为“网卡设备名称 [Windows 接口名称]”。例如“Intel(R) Wi-Fi 6 AX201 160MHz [WLAN]”。
- 清空打印列表会取消所有未完成的本地打印任务，无法恢复。
