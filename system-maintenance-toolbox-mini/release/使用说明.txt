系统维护工具箱 mini

直接运行：
1. Windows 10 / Windows 11 或 64 位 Windows 7：请双击“系统维护工具箱 mini（64位）.exe”。
2. 32 位 Windows 7：请双击“系统维护工具箱 mini（32位）.exe”。
3. 程序启动时会显示“是否允许此应用对你的设备进行更改？”提示，请选择“是”。
4. 不需要安装 Python，不需要运行 build_windows.bat，也不需要打开命令提示符。

本版本更新：
- 每项操作均显示“正在执行”进度条，完成后显示“已完成”，失败时显示“执行失败”和系统原因。
- Wi-Fi 下拉框显示“无线网卡设备名称 [Windows 接口名称]”，例如“Intel(R) Wi-Fi 6 AX201 160MHz [WLAN]”。
- 程序窗口左上角与界面页首均已使用本软件图标。

功能：
- 启用或禁用 Wi-Fi。
- 重启打印机服务。
- 清空本地打印列表（会二次确认）。

提示：
- Wi-Fi 功能会自动识别无线网卡；若识别不到，可在下拉输入框键入系统中的接口名，例如 WLAN 或 Wi-Fi。
- 清空打印列表会取消所有未完成的本地打印任务，无法恢复。
