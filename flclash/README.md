# 山海行 · 国风分流

`ShanHaiXing.js` 是一份为 **FlClash 覆写脚本**设计的中国国风动漫分流方案。它不复制大型脚本中数十个策略组、上百个规则提供者或复杂 DNS 接管逻辑，而是以动态节点分类、10 个清晰的中国元素 Emoji 策略组和 3 份常用规则集覆盖日常使用场景。FlClash 是基于 Mihomo 的跨平台代理客户端；本脚本遵循其 JavaScript 覆写入口，对订阅配置对象进行原地重建。[1]

> **设计原则：少即是多。** 节点交由订阅维护，DNS 服务器仍由用户或订阅自行管理；脚本只重建策略组、规则和规则提供者，从而降低维护成本与订阅兼容风险。

| 范畴 | 山海行的处理方式 | 刻意不做的事情 |
|---|---|---|
| 节点 | 自动识别香港、**澳门**、台湾、日本、新加坡、美国与其他节点；跳过流量/到期等信息行 | 不修改、删除或补全订阅节点 |
| 策略组 | `url-test` 动态区域组加 10 个手动选择组 | 不生成空分组、不建立家宽组、不引入 30+ 业务组 |
| 分流 | 广告、国内、常用 AI、流媒体、Google 与开发服务 | 不追求所有服务的细粒度独立分流 |
| DNS | 关闭 IPv6、启用规则感知 DNS，保留现有解析服务器 | 不覆盖 DNS、TUN、端口或宿主应用开关 |

## 导入方式

在 FlClash 的「配置 → 覆写脚本」中新建脚本后，请点击编辑器右上角的**向下箭头**，选择「导入 URL」，并填入以下地址：

```text
https://raw.githubusercontent.com/JokerXiaoMo/JokerXiaoMo.github.io/main/flclash/ShanHaiXing.js
```

导入完成后，务必点击顶部的「未命名」并填写名称，例如 `山海行`。保存图标只有在内容或名称发生变更时才会启用；填写名称后点击磁盘图标保存，再将该脚本关联至目标订阅并刷新。也可直接复制 [`ShanHaiXing.js`](./ShanHaiXing.js) 的完整内容粘贴，但移动端优先推荐「导入 URL」。建议先在一个测试订阅中验证，再替换日常使用的覆写脚本。

## 澳门节点与延迟测试

节点名称包含中文「澳门 / 澳門」、英文 `Macau / Macao`，或采用 `MO-01`、`MO_01`、`MO01` 等带编号缩写时，都会归入 `🏮 香江灯影`。该组和其他区域节点组使用 Mihomo 的 `url-test`：测试地址为 `https://www.gstatic.com/generate_204`，每 600 秒复测一次，容差为 50 ms，并在首次实际使用时再测速。

> 脚本只能配置测速逻辑，无法在仓库环境中穿透你的订阅节点或手机网络得到真实节点延迟。请在 FlClash 刷新配置后进入「代理」，展开 `🏮 香江灯影` 并执行延迟测试；同一组中延迟最低且可用的澳门或香港节点会成为该 `url-test` 组的优先候选。

## 规则来源与更新

脚本只使用 `blackmatrix7/ios_rule_script` 中的三份 Clash Classical 规则：**AdvertisingLite**、**ChinaMax** 和 **Global**。这些文件在 FlClash 刷新配置时按 24 小时间隔更新；该项目的规则仓库使用 GPL-2.0 许可证，请在再分发时自行审阅其许可条款。[2]

| 规则提供者 | 路由目标 | 作用 |
|---|---|---|
| `shanhai-ad` | `🛡️ 清风拂尘` | 基础广告域名拦截 |
| `shanhai-cn` | `🧧 神州直连` | 常用中国大陆站点直连 |
| `shanhai-global` | `🗺️ 山海行旅` | 常用全球站点代理 |

山海行还内置少量明确域名规则，将常用 AI、视频、Google 与开发服务送入相应的 Emoji 策略组。较完整的 FlClash 分流项目通常会引入大量地区、业务策略组和远程规则提供者；本版仅借鉴其“动态节点分类 + 规则提供者”的架构，而未复制其代码或规则清单。[3]

## 兼容性与边界

脚本要求订阅中存在至少一个有效代理节点，否则将原样返回配置。脚本会**整体替换**订阅自带的 `proxy-groups`、`rules` 与 `rule-providers`，因此不适合依赖订阅内置策略组或自定义规则的场景。如需额外私人规则，应在 `installRules` 内、`MATCH` 规则之前添加。

Android 的 VPN 开关、仅系统代理、应用绕过 VPN 等属于 FlClash 应用层设置，不能由该覆写脚本代替。若期望全应用流量都进入分流，应在应用中正确启用 VPN 功能。[1]

## 验证清单

请刷新订阅后确认代理页至少出现 `🌺 代理选择`、`☁️ 万象节点`、`📜 灵枢智算` 与 `🌺 桃源归途`。随后检查规则页是否下载了 3 个以 `shanhai-` 开头的规则提供者，并访问一个国内站点、一个海外站点与一个 AI/视频服务，按实际解锁能力在策略组中调整地区。
