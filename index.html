砚花行箧 · 开源长卷

番小绯·半纸砚花 V0.2 TUN DNS

面向 BettBox Android VPN/TUN 的国风策略覆写，将节点、专项分流、广告拦截与 TUN DNS 边界题进可解释的配置长卷。

这只行箧里装着什么

“半纸砚花 V0.2 TUN DNS”是面向 BettBox Android VPN/TUN 的 JavaScript 覆写脚本，以 function main(config) 为入口，整理节点识别、策略组、专项分流、广告拦截与传统 DNS 接管边界。

节点归类中国香港、中国澳门、中国台湾、日本、新加坡、美国与未识别地区分池，并单列倍率节点。

运行边界脚本处理进入 BettBox VPN/TUN 的传统 DNS；私人 DNS、浏览器安全 DNS 等为独立边界。

长卷上的策略名

🌺 代理选择总开关，置于策略组首位，可选择万象节点、区域组、倍率组或直连。

☁️ 万象节点全部有效节点的延迟自动池，按真实节点测速并自动切换。

🏮 香江灯影 / 🪭 宝岛团扇中国香港、中国澳门与中国台湾等区域节点的自动择优入口。

📜 灵枢智算 / 🎭 梨园影音AI、影音、影画、Google 与开发服务的专项策略入口。

🛡️ 清风拂尘 / 🧧 神州直连广告拦截开关与中国大陆服务优先直连，未命中流量回归代理选择。

分流与使用一览

规则会依次处理本地与私有目标、广告、AI、影音、影画、Google、开发服务、中国大陆服务与最终未命中流量。使用时，在 BettBox 或兼容 Mihomo 的覆写脚本入口导入正式 URL，并确认“🌺 代理选择”位于策略组首位。
