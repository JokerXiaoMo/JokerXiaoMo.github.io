系统维护工具箱 mini

1. Windows 10 / Windows 11：请直接双击“系统维护工具箱 mini（64位）.exe”。
2. 64 位 Windows 7：请双击“系统维护工具箱 mini（64位）.exe”。
3. 32 位 Windows 7：请双击“系统维护工具箱 mini（32位）.exe”。
4. 程序启动时会显示“是否允许此应用对你的设备进行更改？”提示，请选择“是”。
5. 不需要安装 Python，不需要运行 build_windows.bat，也不需要打开命令提示符。

功能：
- 启用或禁用 Wi-Fi。
- 重启打印机服务。
- 清空本地打印列表（会二次确认）。

提示：
- Wi-Fi 功能会自动识别常见的无线接口；若识别不到，可在下拉输入框键入系统中的接口名，例如 Wi-Fi。
- 清空打印列表会取消所有未完成的本地打印任务，无法恢复。
